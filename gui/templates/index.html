Welcome to OmniExtract

An LLM-based automatic extraction tool built on DSPy, designed for information extraction from literature and documents. It enhances extraction performance through prompt optimization on curated data, and supports batch extraction of multi-property entities from original documents (PDF / XML) and tabular files. A video tutorial is available at OmniExtract - Tutorial.

How it works — a typical session
This is the local GUI server. Configure a model, parse your files, then run extraction / optimization.
1
Configure a model
Connect an LLM provider in Model Configuration and test the connection.
2
Parse documents
Turn PDF / XML into _dataset.json with Document Parsing.
3
(Optional) Optimize prompts
Use Build Optimization Dataset then Prompt Optimization to tune prompts on curated data.
4
Extract & review
Run Document Extraction (original or optimized) or Table Extraction. Track progress in Recent Tasks.
Modules
Each module works on local absolute paths on this server. Use ASCII paths only.
Model Configuration
Set up and test the LLM providers used by every module.
Document Parsing
Convert PDF / XML documents into a structured _dataset.json.
Document Extraction
Extract structured fields from documents — by hand-written prompt or an optimized package.
Build Optimization Dataset
Pair parsed documents with curated ground truth into an optimization dataset.
Prompt Optimization
Run DSPy optimization against your curated dataset to produce an optimized package.
Table Extraction
Parse table files to TSV and extract structured records via a ReAct agent.
