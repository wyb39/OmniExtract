Welcome to OmniExtract

An LLM-based automatic extraction tool built on DSPy, designed for information extraction from literature and documents. It enhances extraction performance through prompt optimization on curated data, and supports batch extraction of multi-property entities from original documents (PDF / XML) and tabular files. A video tutorial is available at OmniExtract - Tutorial.

How it works — a typical session in 4 steps
Follow this path the first time you use OmniExtract.
1
Configure a model
Connect an LLM provider in Model Configuration and test the connection.
2
(Optional) Optimize prompts
Use curated data in Prompt Optimization to produce an optimized extraction package.
3
Run an extraction
Extract from documents with a hand-written schema (Original), an optimized package (Optimized), or from tables.
4
Track & download
Each run returns a workflow status page. Watch progress there and download results when ready.
Recommended Prompt Template
We recommend using the following template to clearly describe the criteria that the information extraction task should follow.
Template
Extract [target information] from [source].
Follow these rules:
1. [rule 1]
2. [rule 2]
...
Exclude the following:
1. [exclusion 1]
2. [exclusion 2]
...
Example
Extract clinical information for patient and healthy control groups from biomedical literature.
Follow these rules:
1. Preserve full group names exactly as reported.
2. When extracting age, report values in years (convert units to years when necessary).
3. When calculating sex percentages, report values rounded to two decimal places.
4. Keep all extracted values precise and cite the source sentence or table.
Exclude the following:
1. Non-human studies.
2. Review articles and meta-analyses.
